### Scenario

## Dataset Guides

### Dataset Overview
* There are mainly two parts in our dataset:
  1. Short conversation between user and bot.
  2. Product pool for retrieval.
* Each conversation has one gold target product; however, there may be other acceptable products in our product pool. We use a fixed LLM to evaluate them.
* There are training, public testing, and private testing splits in this homework. We will only provide training and public testing splits.

### Dataset Size
* **Train**
  * Dialogue: 4,830
  * Product pool: 50,000 (Base pool)
* **Public test**
  * Dialogue: 1,000
  * Product pool: 75,000 (Base 50,000 + New 25,000)
* **Private test**
  * Dialogue: 2,000
  * Product pool: 100,000 (Public 75,000 + New 25,000)

## Retrieval Pipeline & Implementation Guides

### Pipeline
`Load data` ➡ `Retrieve & Rerank` ➡ `Save results`

### `retrieval.py` & `retrieval_utils.py`
* You can **ONLY** modify `retrieve_and_rerank()` in `retrieval_utils.py` to implement your strategy.
* **DO NOT** modify the other parts of the file during testing.
* We will run this file to get your retrieval result:
  ```bash
  $ python retrieval.py --dialogues "dialogues_path" --products "products_path" --output "output_path"
  ```

### `evaluate.py`
* In this task, in addition to the gold standard products, we also accept other relevant products as correct answers.
* We use `Qwen2.5-1.5B-Instruct` to evaluate whether each retrieved product meets the customer's requirements. If the model deems the product acceptable, it is considered a correct answer.
* **Evaluation metrics:**
  * Recall@k (k=10)
  * MRR@k (k=10)
* **DO NOT** modify this file during testing.
  ```bash
  $ python evaluate.py --retrieval-results "path_to_retrieval_result" --dialogues "dialogues_path" --products "products_path" --output "output_path" --batch-size 8
  ```
* *Note:* The TA will use our own `evaluate.py` (which is the same as the one published), so you don’t have to upload this file.
